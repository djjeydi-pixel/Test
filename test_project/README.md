# Проект автоматизированного тестирования

Данный проект содержит тесты для API и UI (Selenium).

## Структура проекта
* `api_tests/` — тесты для API.
* `selenium_tests/` — тесты UI (включая `fixtures/` и `locators/`).

## Установка и запуск
1. Создайте виртуальное окружение: `python -m venv .venv`
2. Активируйте его.
3. Установите зависимости: `pip install -r requirements.txt`
4. Запустите все тесты командой: `pytest`
